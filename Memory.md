# Project Memory

Fuchey is NOT an AI device with a wallet.

Fuchey is a hardware wallet with an integrated AI assistant.

The AI exists to improve the wallet experience.

The wallet does not exist to enable the AI.

"A wallet should not look like a wallet."

During idle time, the device behaves like a desk companion by displaying:
- Clock
- Weather
- SOL Price
- Friendly animations/messages

When wallet functionality is required, it seamlessly transitions into a secure hardware wallet experience.

Any implementation should reinforce this philosophy.
